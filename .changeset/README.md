# Changesets

Hola y bienvenido a Changesets para **glubox**.

Para agregar un cambio a una release futura, ejecuta:

```bash
pnpm changeset
```

Sigue las instrucciones en terminal para indicar el tipo de cambio (`patch`, `minor` o `major`) y redactar el resumen.

Para aplicar los cambios acumulados y actualizar versiones / changelogs:

```bash
pnpm changeset version
```
